# 报警 route 可见性与测量隔离修改记录

## 背景

Phase B 电解槽快照异步投影已经移除同步快照 deadlock，但 `MIXED_ALTERNATE 200000 MQ / 10min` 仍略低于严格门禁。持续输入期间 RabbitMQ 和 stop event 没有线性堆积，因此本轮不扩 consumer、不放大 SQL 批次，只处理 route 可见性竞争和 verifier 测量扰动。

分支：

```text
test/alarm-route-visibility-profile
```

## 代码改动

### ROUTE_MISSING 聚合日志

- `ROUTE_MISSING_RETRY` 不再逐批打印 WARN。
- 新增 `alarm.stop-worker.routeMissingProfileLogEveryBatches`，默认每 `100` 批打印一次聚合日志。
- 聚合日志记录累计批次数、累计行数、最长等待时间、最后一批大小和样例 alarm cid。
- SQL、重试状态机和 MQ ack 语义保持不变。

### verifier 终态完整采样

- 新增压测参数 `alarm.loadtest.terminalOnlyFullSample`。
- 为 `true` 时，持续输入期间只读取 MQ 和 stop event 状态。
- 只有 stop event 可能完成时才执行主表、扩展表、route 和 side effect 完整 count。
- 报告新增 `Terminal-only full sample` 标记。

### 单测

- 新增 `AlarmStopWorkerPropertiesTest`，覆盖 route-missing 聚合日志间隔钳制。
- Java 8 + UTF-8 focused test：`83` 个测试执行，`0` 失败，`0` 错误，`2` 跳过。
- Maven package：通过。

## 运行边界

- 单次 `IN`、multi-values `INSERT` 和 JDBC batch 最大 `500` 条。
- consumer 仍为 `2-4`。
- stop worker 仍为 `4 x 200`。
- snapshot worker 仍为 `2 x 100`。
- 没有增加并发，没有扩大事务。
