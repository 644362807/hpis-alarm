# 本轮修改记录：报警分片配置文档

## 背景

本轮只更新配置文档，不修改 Java 代码、Mapper、接口、测试代码，也不修改 Nacos 实际配置。

目标是把当前分片设计的生产配置、快速测试配置、必配项、选配项和废弃项写清楚，避免继续沿用旧的未来月份预创建、legacy 表兼容等过期口径。

## 当前推荐口径

- 启动时只创建当前月 `00` 三张业务物理表。
- 当前月 actualDataNodes 注册 `00..255`。
- 下个月 actualDataNodes 注册 `00..09`。
- 月末任务只物理创建下个月 `00`。
- 月末任务完成后显式刷新 DataSource。
- 动态建表后主动刷新只是补充机制，不替代 actualDataNodes 预注册。
- `include-legacy-tables` 必须保持 `false`，旧 `alarm_0..4` 系列表不再注册、不再兜底查询。
