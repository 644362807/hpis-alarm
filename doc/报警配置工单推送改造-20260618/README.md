# 报警配置、工单、推送改造文档索引

本目录记录报警配置、报警推送过滤、报警处理和报警工单设计。

## 当前权威口径

当前以 `16-问答确认后的设计修改方案.md` 为准，`15-当前最小修改范围与过时文档清理.md` 作为过时方案清理和最小范围说明。

核心结论：

- `alarm` 只保存报警事实，不新增 `workorder_id`、`alarm_configure_id`、`config_version`。
- `alarm_configure` 承载推送开关、推送策略编码和可选工单模板。
- `alarm_handle` 不再定位为多条动作时间线表，而是报警最终处置记录表。
- 一个报警最多一个工单。
- 一个报警最多一条有效处置型 `alarm_handle`。
- 工单创建、接单、转派、退回、关闭等动作不拆成多条 `alarm_handle`。
- `alarm_handle` 不新增 `status_before/status_after` 这类过程字段；本次只补 `workorder_id`，不新增 `handle_type`。
- 工单当前事实放 `alarm_workorder`；转派直接更新当前负责人和状态，本阶段不设计完整流转历史表。
