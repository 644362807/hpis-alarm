# 报警配置工单推送改造文档索引

本文档目录用于记录报警配置、报警工单、报警推送细分改造的迭代方案、变更范围、风险评审和验证计划。

本目录只记录计划和审核，不修改 Java、XML、SQL、配置文件，也不代表代码已经实现。

## 适用范围

- `hpis-alarm` 报警配置、报警产生、报警处理、报警工单链路。
- `hpis-push` 推送配置、Redis 路由、设备级和行业级推送匹配链路。
- 数据库表范围以《报警配置最小改动方案设计文档》为主。

## 已确认决策

- 字段口径以《报警配置最小改动方案设计文档》为主。
- `alarm_configure.push_message_type` 表示推送细分，不新增额外推送细分字段。
- `alarm_configure.push_message_type` 对应 `active_push_config.message_type`。
- 行业全部报警用 `alarm_configure.alarm_type` 为空或 `*` 表示。
- 设备级和行业级推送配置同时命中时采用 `UNION`，按 `active_push_config_id` 去重。
- 一条报警最多生成一个 `alarm_workorder` 工单实例。
- 工单转派产生处理或流转记录，不新增第二张工单实例。

## 当前代码事实

- 当前报警服务已有 after-commit 异步推送入口，但消息体尚未携带配置来源和 `push_message_type`。
- 当前推送服务已存在 `deviceSn#messageType` 风格的 Redis 路由，但行业级和全局级路由语义尚未落地。
- 当前工单配置表、工单实例表和工单服务尚未落地。
- 当前 `alarm`、`alarm_handle` 属于分片链路，新增字段必须同步分片建表和 Mapper 批量 SQL。
