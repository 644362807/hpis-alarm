# 报警总结文档索引

## 文档定位

本目录用于沉淀 `hpis-alarm` 文档总结、反思、学习路线、面试题和后续文档治理思路。所有文档都以现有 `doc/` 资料和当前权威口径为基础，不替代原始设计文档。

阅读时必须先遵守一条规则：过时、旧方案、历史参考文档只能用于理解演进，不能影响当前最终结论。

## 推荐阅读顺序

| 顺序 | 文档 | 用途 |
| --- | --- | --- |
| 1 | `报警全量文档总结与改进思考-20260704.md` | 建立当前权威口径、核心链路、过时隔离和资料索引。 |
| 2 | `报警文档复盘反思与改进思考-20260705.md` | 从文档和架构演进中提炼经验、教训和改进原则。 |
| 3 | `报警模块学习路线与实践清单-20260705.md` | 给新人或接手者安排分阶段学习路径和实践任务。 |
| 4 | `报警模块面试问题清单-20260705.md` | 用问答方式检查候选人或接手者是否真正理解 alarm 链路。 |
| 5 | `报警文档体系完善思路-20260705.md` | 规划后续文档如何维护、归档、复核和防止旧方案污染。 |

## 使用建议

- 做代码修改前：先读总结、复盘和文档体系完善思路。
- 做交接培训前：先读学习路线，再结合面试问题做检查。
- 做设计评审前：用面试问题清单里的高阶题反向审查方案。
- 做文档维护前：以文档体系完善思路中的模板和复核流程为准。

## 当前边界

- 本目录不记录 `target/` 构建产物。
- 本目录不删除原始 `doc/` 历史文档。
- 本目录不把过时工单方案、旧 `alarm_id % 5` 分片方案、旧自研 MQ 聚合方案作为当前实现依据。
